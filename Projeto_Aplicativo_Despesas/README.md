# Projeto Desafio — Aplicativo de Divisão de Despesas

Este repositório contém os arquivos do projeto desafio para desenvolvimento de um aplicativo de divisão colaborativa de despesas, usando plataformas **No-Code/Low-Code** como **AppSheet** ou **FlutterFlow**.

## 📋 Sobre o Desafio

O objetivo é criar um aplicativo funcional que permita a um grupo:
- Cadastrar pessoas e despesas
- Definir pesos de participação por despesa (ex: 1.0 = integral, 0.5 = meia)
- Registrar pagamentos de despesas e pagamentos diretos entre pessoas
- Calcular automaticamente saldos (valor a receber / a pagar / quitado)
- Validar regras de negócio (pesos negativos, divisão por zero, pagamentos inválidos, etc.)

## 📌 Entregáveis Esperados

Cada grupo deve entregar:
1. Aplicativo funcional (link ou forma de acesso)
2. Nome dos integrantes
3. Descrição do problema escolhido
4. Modelo de dados ou diagrama
5. Lista de funcionalidades implementadas
6. Descrição das regras de negócio
7. Roteiro dos testes realizados
8. Exemplos de cálculos dos saldos
9. Limitações / próximas versões
10. Apresentação ou vídeo demonstrando o app

## ✅ Critério Principal

> **Não basta criar um aplicativo que tenha telas e botões.**  
> O grupo deve demonstrar que transformou o problema em:  
> **problema → requisitos → modelo de dados → regras de negócio → aplicativo → testes → solução funcional**  
> E conseguir explicar/defender tecnicamente cada decisão.
